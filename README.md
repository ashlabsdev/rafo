# Rafo

**Engineering Calculation Platform by AshLabs**

Rafo is a modular engineering calculation platform designed to provide accurate and interactive calculations across electrical engineering, AC fundamentals, complex numbers, impedance, and radio frequency engineering.

The project begins with electrical and RF fundamentals and is designed to expand into advanced engineering calculations and analysis tools.

## Tech Stack

### Frontend

* Angular
* TypeScript
* RxJS
* Angular Material / Custom CSS

### Backend

* Python
* FastAPI
* REST API
* JSON

### Testing

* Pytest
* Angular Testing

### Deployment

* Frontend: Vercel
* Backend: Render / Railway
